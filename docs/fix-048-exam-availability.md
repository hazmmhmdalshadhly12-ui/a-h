# دليل تطبيق إصلاح 048 — توفر الامتحانات المنشورة

> تاريخ الإصلاح: 22–23 نوفمبر. البلاغ الأصلي: امتحان «عام» منشور منذ ساعات
> كان متاحًا عند نشره ثم ظهر للطلاب «غير متاح حالياً» مع شارة «منتهي»،
> رغم أن حقل تاريخ الانتهاء (`end_at`) فارغ.

## 1) سبب المشكلة

دالة `exam_attempt_deadline` كانت تفرض **حدًا عالميًا = `start_at` + مدة الامتحان**.
فأي امتحان بلا `end_at` كان يتقفل تلقائيًا بعد مدته من موعد بدئه — حتى لو
لم يدخله أي طالب — فتظهر البطاقة «منتهي / غير متاح حالياً».

مثال البلاغ: امتحان عام بدأ 04:08 ومدته 30 دقيقة → أُغلق 04:39 globally،
وطلاب الساعة الثانية عشرة وجدوه «غير متاح».

## 2) ما الذي تغيّر

### قاعدة البيانات — `supabase/migrations/048_exam_window_fix.sql`
- نافذة التوفر = **[`start_at` , `end_at`] فقط**. بلا `end_at` يظل الامتحان
  متاحًا لمن لم يدخله دون تاريخ انتهاء.
- **المدة لكل طالب من بدء محاولته هو** (+60 ثانية مهلة إرسال التسليم الآلي)
  — نفس نموذج المحاولات؛ تحديث الصفحة لا يصفّر المؤقت.
- `end_at` (لو محدد) يظل **صارمًا بلا مهلة**.
- منع تجاوز المؤقت محفوظ: التسليم المباشر عبر RPC بلا محاولة مسجلة
  مرجعه `start_at` الرسمي (لا يُمنح وقت جديد بالاستدعاء المباشر).
- `CREATE OR REPLACE` بنفس التوقيع → **لا خطأ 42P13**، قابل لإعادة التشغيل
  بأمان، ولا يحذف بيانات ولا يغير مخططًا.

### الواجهة — `ExamCard.jsx`
- شارة «انتهى» والزر المقفول صارا يظهران **فقط عند وجود `end_at` منقضٍ**.
  سابقًا كانت تُحسب `start_at` + المدة — وهو ما أصّل خطأ الإغلاق في الواجهة أيضًا.

## 3) خطوات التطبيق على الإنتاج (بالترتيب)

1. **قاعدة البيانات (خطوة يدوية واحدة):**
   Supabase → SQL Editor → استعلام جديد → الصق كامل محتوى
   `supabase/migrations/048_exam_window_fix.sql` → **Run**.
   - لو ظهرت رسالة خطأ «048 يتطلب تنفيذ 047…» فمعناه أن 047 لم يُنفَّذ على
     هذه القاعدة — نفّذ `047_exam_access_part1.sql` ثم `part2` ثم 048.
   - لا تُمس أي بيانات؛ يمكن تشغيله أكثر من مرة بأمان.
2. **الواجهة:** تُنشر تلقائيًا مع كل دفع إلى `main` عبر GitHub Actions
   (Deploy to GitHub Pages). للنشر اليدوي: تبويب Actions → اختر
   «Deploy to GitHub Pages» → Run workflow.
3. **التحقق بعد التطبيق:**
   - صفحة الامتحانات: بطاقة الامتحان العام بلا `end_at` أصبحت
     «متاح الآن» بزر «حل الامتحان».
   - امتحان لم يبدأ بعد يظهر «لم يبدأ» حتى موعد `start_at`.
   - دخول الطالب في أي لحظة داخل النافذة يبدأ عدّاده من دخوله،
     ولدية تسليم واحد فقط لا يتكرر.

## 4) السلوك بعد الإصلاح — ملخص سريع

| الحالة | قبل 048 | بعد 048 |
| --- | --- | --- |
| `end_at` فارغ | يتقفل بعد المدة من `start_at` | متاح بلا تاريخ انتهاء |
| `end_at` محدد | يُغلق عند `end_at` | يُغلق عند `end_at` (كما هو) |
| مدة الطالب | من `start_at` الرسمي | من بدء محاولته هو |
| امتحان متزامن (حصة) | — | حدد `end_at` = البدء + المدة |
